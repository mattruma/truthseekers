# Meetings

This directory contains discussion materials for Truth Seekers Club meetings.

## Meeting 01 — What Is Truth?

Our first meeting explores three foundational questions: 

- What is truth?
- Can we know truth?
- Does truth matter?

Together, we'll examine competing perspectives, challenge assumptions, and consider how reason, evidence, belief, and experience shape what we accept as true.
