# Appeal to Tradition

## Description

Claims that a belief or practice is correct or superior simply because it has existed for a long time.

## Example

> We've always done it this way, so this must be the best way to do it.

## Explanation

A tradition may have good reasons behind it, but its age alone does not establish that it is correct or optimal.

The practice should be evaluated based on its merits.
